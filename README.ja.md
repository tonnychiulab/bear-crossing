> 台湾固有の亜種「**タイワンツキノワグマ**（台湾黒熊）」が主人公の 2D レトロアーケード風・道路横断アクション Web ゲーム。  
> **OpenSpec** 仕様駆動開発に基づき、ピュアな HTML5 Canvas 2D で描画。外部リソースへの依存はゼロです。

🎮 **[今すぐオンラインでプレイ (GitHub Pages)](https://tonnychiulab.github.io/bear-crossing/)**

---

## 🎮 ゲームの特徴

- 🐻 **象徴的なタイワンツキノワグマ**：胸元の白い「V」字マークや丸い黒耳を忠実に再現した 32×32 ドット絵。待機・ホップ跳躍・被弾スピンの各アニメーションを実装。
- 🛵 **台湾ならではの乗り物たち**：青白の原付スクーター、黄色いタクシー、伝統的な緑白の路線バス、そしておなじみの黄青ツートンゴミ収集車。
- 🗺️ **巡回する 4 つのテーマステージ**：
  1. **市街地道路 (Urban Street)**：スクーターの大群と信号機による車止めルール。
  2. **高速道路 (Highway Express)**：超高速で駆け抜ける大型バスや乗用車。
  3. **山岳道路 (Mountain Trail)**：落石やゴミ収集車が行き交う中横の未舗装砂利道。
  4. **秀姑巒渓 (River Rapids)**：激流、流木、そして**定期的に泡を立てて潜水するカメ**。
- 🎋 **アイテムと特殊ギミック**：
  - **タケノコ (竹筍)**：一時的なスピードアップでジャンプのインターバルを半減。
  - **ハチミツの壺 (蜂蜜罐)**：黄金のハニカムシールドを展開し、交通事故や水没から 1 回身を守る。
  - **信号機 (紅綠燈)**：市街地レーンの信号が赤になると、車が完全に一時停止。
  - **カメの潜水 (烏龜潛水)**：カメの群れが周期的に水没。水中に沈んでいる間に乗ると溺れてミスになります。
- 🎵 **完全 Web Audio API による 8-bit サウンド**：外部音声ファイルを一切使わず、ジャンプ音・衝突音・ステージクリアファンファーレおよび 4 つのステージ専用 Chiptune BGM をリアルタイムにプログラム合成。ワンクリックでミュート切り替え可能（`🔊/🔇`）。
- 📋 **ワンクリック戦績シェア**：ゲームオーバー時に絵文字入りのクリア戦績テキストをクリップボードに素早くコピー。

## 🏗️ 技術アーキテクチャ

本プロジェクトは**完全静的アーキテクチャ**を採用しており、Node.js やビルドツールのインストールは一切不要です。ブラウザでファイルをダブルクリックするだけでオフライン動作します：

```text
bear-crossing/
├── index.html              # ゲームコンテナ、HUD、Canvas ビューポート
├── index.mvp.html          # 初代 DOM + SVG MVP バックアップ
├── css/
│   └── style.css           # レトロアーケードスタイル＆レスポンシブ枠
└── js/
    ├── audio.js            # Web Audio API 8-bit サウンドシンセ＆BGM シーケンサー
    ├── sprites.js          # パレット式文字列マトリックスによるドット絵生成器
    ├── tilemap.js          # 4 ステージのタイル描画・レーン定義・信号機ロジック
    ├── entities.js         # プレイヤークマ、乗り物、流木/カメ、アイテム衝突判定
    └── game.js             # 60FPS ステートマシンメインループ＆スコア共有
```

## 🛠️ 使用した AI Skills とワークフロー

今回のアップグレードでは、専門的な AI エージェントスキルを活用して仕様のすり合わせと実装を行いました：

1. **`/grill-me` (Antigravity 対話型アライメント)**  
   - 決定木インタビューを通じて「中規模アップグレード ⭐⭐⭐」の範囲を定義。32×32 ドット絵、プログラム自動生成、多ステージ進行、依存ゼロの静的配信方針を決定。
2. **`openspec-propose` (OpenSpec 提案生成)**  
   - 合意事項に基づき、標準化された OpenSpec 成果物（Proposal、Delta Specs、Technical Design、17 分類タスク）を一括構築。
3. **`openspec-apply-change` (OpenSpec タスク適用)**  
   - タスクリストに沿って、CSS スタイル、ドット絵生成、ステージマップ、各種エンティティ、Web Audio 音響システムを段階的に実装し、100% の検証を完了。

## 🎨 素材・音源の帰属および知的財産権の明記

「**100% プログラム自動生成・外部アセット依存ゼロ**」の設計方針に基づき、すべてのグラフィックと音源はコード上で生成されています：

1. **ドット絵グラフィック (Pixel Art Sprites)**：
   - **クマと車両**：[`js/sprites.js`](./js/sprites.js) 内の独自パレット式文字列マトリックスを用いてメモリ内で動的描画。外部のスプライトシートや未許諾画像は一切使用していません。
   - **文化的な着想**：台湾固有の保護動物「タイワンツキノワグマ（*Ursus thibetanus formosanus*）」の特徴である胸元の白い「V」字斑紋を再現。台湾の地元車両（スクーター、黄色いタクシー、緑白のバス、青黄のゴミ収集車）を描き起こしました。
2. **音響および音楽 (Audio & Music)**：
   - **100% プロシージャル合成**：W3C 標準の **Web Audio API**（`OscillatorNode` 矩形波/三角波/ノコギリ波、`GainNode`、`BiquadFilterNode`）を使用し、[`js/audio.js`](./js/audio.js) でリアルタイムにオシレーターを駆動。外部の MP3/WAV/OGG ファイルは使用していません。
3. **ゲームデザインの起源と歴史**：
   - **アーケードゲームへのオマージュ**：1981 年の名作アーケードゲーム『フロッガー』（コナミ）の伝統的な道路・河川横断メカニクスに敬意を表し、台湾の交通事情や秀姑巒渓の自然地理を融合。
   - **初代プロトタイプの保存**：初期の DOM + SVG + 絵文字による MVP は [`index.mvp.html`](./index.mvp.html) にそのまま保管されています。
